[h1]Restoring the Legacy[/h1]
This mod is a simple modern reimagination of the following first-generation mods:
[list]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=409865621]TransportLineColorMod[/url]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=408760323]Auto Line Color[/url]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=1415090282]TransportLineColorMod[/url]
[/list]

The legacy mods are often reported as not working, and this mod has an alternative approach.

Salute to the departed forebears, as we venture into the future.

[h1]Mod Effects[/h1]
This mod is very simple. This mod picks a random color from the CSS named colors list for your public transport lines. That's it.

CSS named colors list: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/named-color

This mod does not accept custom color lists, but do you really need those custom lists, when the standard CSS list already has about 150 colors?

Note: Transport Lines Manager already has a custom line color initializer, so don't use this mod together with TLM.

Note: no district-level automation (color/name); those are left for players to specify, or for future mods to implement.
